## 📌 Featured Project: BitGuard

<a href="https://github.com/MehmetEmin-Y/Bit-Guard">
  <p align="center">
    <img src="https://github-readme-stats.vercel.app/api/pin/?username=MehmetEmin-Y&repo=Bit-Guard&theme=radical&border_radius=10" alt="BitGuard Repo Stats"/>
  </p>
</a>

> A **network transfer tool** that verifies data integrity with SHA-256, encrypts traffic with TLS 1.3, and automatically re-requests only the corrupted chunk if a transfer is damaged (instead of restarting from scratch).  
> Built to understand hands-on the gap between a system that *looks* secure and one that *actually* is.
